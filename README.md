# 다운로드 경고 시험

설치 파일을 인터넷에서 받을 때 브라우저와 백신이 어떤 경고를 띄우는지 확인하려고 만든 임시 저장소입니다.

실제 프로그램이 아니고 쓸모 있는 기능이 없습니다. 받거나 설치할 필요가 없습니다.

## 릴리스에 있는 파일

| 파일 | 내용 |
|---|---|
| `HwpPdfTest-setup.exe` | C# 시험 프로그램의 사용자별 설치 파일 (Inno Setup) |
| `HwpPdfTest.exe` | C# 시험 프로그램 |
| `HwpPdfTest-setup.zip` | 위 설치 파일을 ZIP으로 묶은 것 |
| `HwpPdfTest.msi` | 아무것도 설치하지 않는 가장 작은 MSI |
| `HwpPdfTest-py-setup.exe` | PyInstaller로 만든 시험 프로그램의 사용자별 설치 파일 (Inno Setup) |

## 시험 프로그램이 하는 일

- 그냥 실행하면 옆에 `ran_이름.txt` 파일 하나를 만들고 끝납니다.
- 인터넷에 접속하지 않습니다.
- C#판은 명령줄로 원본과 저장 경로를 주면 PC에 설치된 한글 프로그램을 불러 PDF로 저장합니다.
- 설치 파일은 `%LOCALAPPDATA%\Programs` 아래에 설치하며 관리자 권한을 쓰지 않습니다. 윈도우 설정의 앱 목록에서 지울 수 있습니다.
